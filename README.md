# bili-focus · 专注 B站

**大刀阔斧砍掉干扰，把 B站留下来当学习工具。**

直接修改 B站网页，保留原生搜索、账号登录、老师投稿和播放器。没有另起一个插件主页，也没有「猜你喜欢」。

搜索栏旁可切换「专注模式／正常 B站模式」。退出专注时需在弹窗中逐项勾选三条确认，才能启用退出按钮；切换后页面自动刷新。正常模式保留 B站原生页面与搜索请求，已收藏的老师、课程和外观设置不会丢失；再次点击「开启专注」即可恢复。

## 砍掉什么

- 首页推荐流、轮播横幅、频道导航、热榜／娱乐入口、广告。
- 搜索热词和历史建议；允许搜索视频及 UP 主，搜索请求剥离 Cookie。
- 老师主页的关注、私信、举报、黑名单等社交操作入口。
- 播放页的弹幕、评论、相关推荐、点赞投币分享等互动区。
- 个人头像及其整个下拉菜单；右上角直接显示昵称和「退出登录」，未登录时显示「登录」（搜索页不显示账号入口）。

账号文字区位于右上角；各页面左上角的小电视图标可直接返回主页，不再额外刷新一次；在首页点击则平滑回到顶部。这是界面精简，不是网络拦截，隐藏内容可能仍由 B站加载。

## 留下什么

### 老师收藏

在老师主页点击「收藏老师」，填写昵称并**选择分类**；老师空间的「课堂」标签可直接打开。已收藏时再次点击直接取消收藏。也可以点击「我的老师」旁的「添加老师」，输入主页链接或 UID。

收藏卡片显示账号头像。老师页收藏优先使用页面头像，手动添加通过公开资料接口获取；遇到网络错误、风控或图片加载失败会退回昵称首字。旧收藏会自动迁入「未分类」，已有昵称和配色不变。

### 课程收藏

放在老师模块上方。点击「我的课程」旁的「添加课程」，**仅通过手动输入完整 B站视频 URL 添加**。支持普通视频 `https://www.bilibili.com/video/BV…/`、`…/av…/`，以及 B站课堂 `https://www.bilibili.com/cheese/play/ep…`、`…/ss…`。不支持短链接、番剧或普通视频合集地址。

自动获取视频标题、封面和分 P 数量，可以自定义课程名。获取失败时显示错误并保留表单，不创建没有资料的课程。

多 P 课程卡片显示「上次看到第几 P」，课堂课程显示「上次看到第几课」。点击卡片从对应分 P 或课时打开；添加课堂课时链接后，初次点击会打开所添加的课时。只有已收藏的课程播放超过约 1 秒才更新进度；不记录播放秒数，不自动收藏其他视频，也不保存一般浏览历史。付费课堂内容仍需用户在 B站拥有相应观看权限。

老师和课程卡片右上角的齿轮可以编辑昵称／名称与分类；修改不会覆盖头像、封面或分 P 进度。

### 分类与外观

老师和课程各有独立分类，每个分类用横线分隔。可以添加分类；删除前会明确提示**同时删除分类内全部收藏**。每个模块至少保留一个分类，最后一个不可删除。

主题和明暗采用等宽下拉框。支持纯白、B站蓝、B站粉、曜黑、青绿；蓝／粉／绿支持跟随系统或指定明暗。纯白与曜黑固定对应明暗。首页和搜索结果页共享配色，搜索页的筛选、卡片文字和分页也随主题变化。

## 安装／更新

当前版本：`releases/bili-focus-0.4.11.zip`；可用 `npm run package` 重新生成。解压 ZIP 后，在 Chrome 扩展管理页开启开发者模式，点击「加载已解压的扩展程序」，选择解压后包含 `manifest.json` 的文件夹。版本更新见 [CHANGELOG.md](CHANGELOG.md)。

也可以直接加载仓库根目录进行开发。尚未发布到 Chrome 商店：

1. 打开 `chrome://extensions`（Edge 使用 `edge://extensions`）。
2. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择**仓库根目录**，不是 `src`。
3. 打开 `https://www.bilibili.com/`。

更新文件后，先在扩展管理页点击「重新加载」，再刷新 B站标签页。发行 ZIP 可通过 `npm run package` 从版本号与源文件重新生成。0.3.0 增加了公开资料接口 `api.bilibili.com` 的访问权限，若浏览器提示权限变化需重新启用插件。

若旧版本报 `ERR_FILE_NOT_FOUND`，重新加载扩展后再访问 B站。根目录的 `study.html` 只用于旧入口升级提示，不会自动跳转造成循环。不要卸载，卸载会清除本地收藏。

## 数据与权限

- `storage`：老师、课程、分类、已收藏课程的分 P 位置、外观偏好，全部保存在 `chrome.storage.local`。
- `api.bilibili.com`：仅用于公开头像／课程元数据，请求不携带登录 Cookie。
- 内容脚本：仅在 `www.bilibili.com`、`search.bilibili.com`、`space.bilibili.com` 的 HTTPS 页面运行。
- 没有账号上传、统计 SDK、云端同步，也不读取 Cookie 或浏览历史。
- 昵称取自原站 DOM；文字按钮复用原站登录／退出事件，插件不复制登录凭证。

收藏写入通过后台队列串行处理，避免多个标签页同时添加时互相覆盖。删除分类与其中收藏在同一次存储更新中完成。

## 无 Cookie 搜索

通过 Chrome 声明式网络规则移除搜索请求的 `Cookie` 请求头：覆盖 `search.bilibili.com`、B站搜索 API，以及搜索页面发往 `api.bilibili.com` 的请求。视频结果、账号结果和分页使用原站界面。

这不是匿名代理：IP、关键词、浏览器信息，以及原站自行放入 URL 的参数不在此保证范围。播放页面和非搜索页面的登录请求不移除 Cookie，保留原站高清权限。

0.4.0 新增 `declarativeNetRequestWithHostAccess` 与搜索域访问权限，更新后需重新加载／启用插件才能应用网络规则。依据 [Chrome 声明式网络请求文档](https://developer.chrome.com/docs/extensions/reference/api/declarativeNetRequest)。

## 项目目录

```text
manifest.json                 扩展入口与权限声明
study.html                    旧版入口兼容提示
src/
  background/worker.js        元数据请求、数据迁移、串行存储操作
  core/shared.js              页面路由、老师 UID 与搜索链接
  core/library.js             分类／收藏／进度的数据规则
  content/app.js              页面装配、收藏交互、播放进度
  content/header.js           顶栏与个人菜单精简
  content/ui.js               分类、卡片与表单
  rules/search-privacy.json   搜索请求去 Cookie 规则
  styles/                    原站净化、主题与收藏区样式
  upgrade/                   旧版升级提示脚本与样式
scripts/check.cjs             源码语法检查
tests/                        数据回归与浏览器集成测试
docs/                         设计说明、验收记录与截图
```

扩展运行无需构建和安装依赖。开发验证需要 Node.js 20+：

```sh
npm ci
npm run check
npm test
npm run test:browser
```

浏览器测试通过 Playwright 使用本机 Chrome，使用模拟 B站页面、存储和元数据接口，执行真实后台代码与内容脚本。不会修改你的 Chrome 收藏或登录会话。

搜索隐私实测（需要 OpenSSL 和测试浏览器）：

```sh
npx playwright install chromium
npm run test:privacy
```

该测试使用临时浏览器、虚构 Cookie 和本机 HTTPS 服务，不读取个人账号。

## 已知边界

B站会调整页面结构，CSS／DOM 规则可能需要维护。老师公开资料接口可能受风控限制，课程元数据也可能因下架、地区或访问限制而获取失败。真实登录态的原生菜单和完整播放兼容性仍需要人工回归，不能用模拟测试代替。

不提供笔记、番茄钟、自动推荐或学习时长排名。不承诺拦截独立直播域、移动端或所有 B站变体页面。
