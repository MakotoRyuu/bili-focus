# 设计说明

bili-focus 的主路径是「找到老师／手动添加课程 → 选择内容 → 专心看」。直接删减 B站原生网页，不提供独立应用式首页。

首页由老师、课程两个模块组成。每个模块有独立分类：分类名后接一条横线，下面排列收藏卡片。老师显示头像、昵称，课程显示封面、名称和多 P 续看信息。课程只能通过输入 URL 添加，避免自动收集零散视频。

新增收藏必须明确选择分类。分类删除弹窗说明会一并删除内容，最后一个分类受 UI 和后台双重保护。旧数据自动归入默认分类；后续添加时仍需主动选择分类。

原生顶栏保留搜索与账号。个人头像紧邻搜索框，头像点击不导航，悬浮菜单只留下昵称和原生退出登录操作。所有支持页面都有返回主页入口。未知个人菜单布局采用隐藏回退，后续需按 B站更新适配。

收藏及分类通过后台消息统一写入同一个 library 对象，队列串行执行，避免并发写入丢失。原始旧版 teachers 数据保留作迁移来源，但新版只更新 library。

元数据后台请求不携带 Cookie，不复制登录。图片仅接受 B站 hdslb.com 图片域，失败时老师卡片回退首字，课程封面回退提示。昵称、分类、课程名使用 textContent 渲染。
