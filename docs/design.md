# 设计说明

bili-focus 的主路径是「找到老师／手动添加课程 → 选择内容 → 专心看」。直接删减 B站原生网页，不提供独立应用式首页。

首页由课程、老师两个模块依次组成，每个模块有独立的添加按钮。每个模块有独立分类：分类名后接一条横线，下面排列收藏卡片。老师显示头像、昵称，课程显示封面、名称和多 P 续看信息。课程只能通过输入 URL 添加，避免自动收集零散视频。

新增收藏必须明确选择分类。分类删除弹窗说明会一并删除内容，最后一个分类受 UI 和后台双重保护。旧数据自动归入默认分类；后续添加时仍需主动选择分类。

原生顶栏保留搜索与账号。取消个人头像和悬浮菜单，右上角文字显示昵称与退出登录；访客显示登录。原生事件仍用于登录／退出。所有支持页面都有小电视主页入口。

收藏及分类通过后台消息统一写入同一个 library 对象，队列串行执行，避免并发写入丢失。原始旧版 teachers 数据保留作迁移来源，但新版只更新 library。

元数据后台请求不携带 Cookie，不复制登录。原生视频／账号搜索通过网络规则移除 Cookie，保持正常播放请求的登录状态。图片仅接受 B站 hdslb.com 图片域，失败时老师卡片回退首字，课程封面回退提示。昵称、分类、课程名使用 textContent 渲染。
