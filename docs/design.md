# 设计说明

bili-focus 的主路径是「找到老师／手动添加课程 → 选择内容 → 专心看」。直接删减 B站原生网页，不提供独立应用式首页。

首页将课程和老师分类排列在同一条可调整的顺序中，分类可跨类型上下移动。顶部各有一个「添加分类」和「添加资源」按钮，按钮内选择课程或老师。分类名后接一条横线，下面排列收藏卡片。老师显示头像、昵称，课程显示封面、名称和多 P 续看信息。课程只能通过输入 URL 添加，避免自动收集零散视频。

新增收藏必须明确选择分类。分类删除弹窗说明会一并删除内容，每种类型的最后一个分类受 UI 和后台双重保护。旧数据自动归入默认分类；旧版分类按原有课程在前、老师在后的顺序迁移，后续添加时仍需主动选择分类。

原生顶栏保留账号。取消个人头像和悬浮菜单，右上角文字显示昵称与退出登录；访客显示登录。原生事件仍用于登录／退出。所有支持页面都有小电视主页入口，「退出专注／开启专注」按钮在小电视旁。原生顶部搜索栏在专注模式下隐藏；搜索集中到首页中央的常驻搜索框（节点不随重渲染重建，输入内容不丢失），提交后进入无 Cookie 搜索结果页，结果页保留原生搜索框。

收藏及分类通过后台消息统一写入同一个 library 对象，队列串行执行，避免并发写入丢失。原始旧版 teachers 数据保留作迁移来源，但新版只更新 library。备份导出把归一化后的 library 与外观设置写入本地 JSON；导入经后台校验归一化后整体替换 library 并应用外观，非法文件不会触碰现有数据。卡片移除采用撤销式恢复，经由普通 item.save 路径写回（含进度校验），不引入额外存储通道。

元数据后台请求不携带 Cookie，不复制登录。原生视频／账号搜索通过网络规则移除 Cookie，保持正常播放请求的登录状态。图片仅接受 B站 hdslb.com 图片域，失败时老师卡片回退首字，课程封面回退提示。昵称、分类、课程名使用 textContent 渲染。
